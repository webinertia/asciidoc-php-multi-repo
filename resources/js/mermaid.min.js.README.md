# Vendored Mermaid build

`mermaid.min.js` in this directory is the upstream Mermaid browser bundle, published unchanged.

| Field | Value |
| --- | --- |
| Package | `mermaid` |
| Version | 11.4.1 |
| Source | https://cdn.jsdelivr.net/npm/mermaid@11.4.1/dist/mermaid.min.js |
| Upstream repository | https://github.com/mermaid-js/mermaid |
| Licence | MIT |

The bundle sets `globalThis.mermaid` and bundles its own dependencies, including DOMPurify, so no
other script is required and no request leaves the site at runtime.

Upgrading means replacing the file and updating this table. The published asset name carries a
content hash, so a replacement invalidates the cached copy automatically.

`resources/js/mermaid.js` is the loader this package owns. It is a separate asset on purpose: the
vendored bundle is only emitted on a page that contains a `[source,mermaid]` block.
